# 素数大富豪 数譜検討

素数大富豪＋の標準大会数譜を再生し、好きな局面から自分で着手する通常2人戦用の検討サイトです。静的ファイルだけで動き、対戦サーバーは不要です。

## GitHub Pages

このフォルダの内容すべてを、専用リポジトリのルートへアップロードします。Settings → Pages → Deploy from a branch で公開ブランチと `/ (root)` を指定してください。公開URLとリポジトリ名は任意です。サブパスにも対応しています。

公開先のリポジトリ作成・アップロード・Pages設定は行っていません。

## 操作

- 両者の初期手札を含む数譜を貼り付けるか、クリップボードまたはテキストファイルから読み込みます。複数局は対局選択で切り替え、各局の検討を保持します。
- 本譜の局面を選んで「ここから検討」。手番の札をクリックし、場に出す・ドロー・パスを選びます。両者を手動で操作できます。
- 本譜と全分岐を残し、「戻る」や一覧で比較します。上がり後に続ける場合は、上がり前の局面へ戻って別の手を選びます。
- 合成数は見せ札と材料札を別々に選び、材料式に `×`・`^` を挿入します。札の表記を直接入力する方法もあります。
- 山札編集は札の種類・枚数を保った並べ替えです。補完札は破線で表示します。
- 検討JSONと検討リンクには全分岐・山札・現在局面を保存します。ドロー後は出札かパスをするか、ドローを取り消してから保存してください。
- ブラウザ内へ自動保存します。新しい数譜の読込は作業を置き換えるので、必要な検討は先にJSON保存してください。

## 山札の再構成

通常デッキ（A〜K各4枚、X2枚）を物理札IDで管理します。数譜全体から後続のドローとペナルティ札を読んで、分岐局面の山札を推定します。そこで山札にある札だけを推定対象とし、未来の手札やまだ戻っていない札を混ぜません。不明な初期山札は残り札をseedで補完します。合成数の材料は即座に底へ戻り、表示札は出した順に予備軍へ積み、場が流れたときに戻します。

初期山札の順序はドロー記録を優先します。戻り札の順序と記録が食い違う場合も、山札内の札を並べ替えて記録へ追従し、順序調整の注記を表示します。「流す札をシャッフル」では検討の場流れで戻す札だけをseed付きでシャッフルします。シャッフル済みの実順序そのものを復元できたとは限りません。数譜に記録された札の並びと不明部分の補完を区別して表示します。

不足札・重複札・手番違い・上がり記号の矛盾は該当行をエラーとして示し、存在しない札は追加しません。旧数譜で `[R]` が全面的に省略されている場合は `[RR]` から革命状態を復元し、出力に `[R]` を補います。全ペナルティ札がない旧 `P(枚数)` 記録は、自動推測で修復しません。

## 対応範囲

通常54枚の2人戦、初期手札枚数は数譜から取得、合成数あり／なし、通常／1枚／見せ札枚数ペナルティ。ハーフ・特殊ルール・多人数戦・CPU自動対戦は対象外です。本譜の成功・失敗は元記録に従い、検討で選んだ手を新たに判定します。

数値はBigInt。64ビット未満は決定的なMiller–Rabin、以上は16底の検査通過として扱い、素数の証明とは表示しません。材料式は積と右結合の累乗を専用パーサーで処理し、evalは使用しません。処理はWeb Workerで動かします。

## 数譜の受け渡し

`integration.html` に案内、`integration.mjs` に組込用ヘルパーがあります。公開後に素数大富豪＋や数譜DB側から次のように開けます。

```js
import { replayURL } from './integration.mjs';
const url = replayURL(REPLAY_SITE_URL, completeStandardKifu, {
  penalty: 'normal', returnMode: 'ordered', seed: 20261009,
});
window.open(url, '_blank', 'noopener,noreferrer');
```

数譜はURLフラグメントの `#kifu=...` で渡します。受信側は `?kifu=...` にも対応します。検討リンクは `#analysis=...` に圧縮JSONを格納します。長いリンクは受け渡し環境の制限があるためJSON保存も利用できます。外部サイトへのボタン追加には、公開URLを確定してそのサイト側の実装へ組み込む必要があります。

## ローカルで開く

HTTPサーバーでこのフォルダを配信して開きます。`file://` 直開きはES Modules／Web Workerの制限があるため使用しません。ビルド・npm依存・APIキーは不要です。
